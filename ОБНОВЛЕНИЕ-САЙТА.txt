ОБНОВЛЕНИЕ САЙТА «ГОРИЗОНТ»

В архиве находится полный комплект файлов сайта, включая игру «Собери персонажа» с Милой и Мишей.

КАК ОБНОВИТЬ САЙТ ЧЕРЕЗ GITHUB DESKTOP (рекомендуемый способ)
1. Скачай архив и распакуй его.
2. Открой локальную папку репозитория gorizont-site в GitHub Desktop: Repository → Show in Explorer.
3. Открой распакованную папку gorizont-site-main.
4. Скопируй ВСЁ её содержимое в папку репозитория gorizont-site, согласись на замену совпадающих файлов.
   Важно: копировать нужно содержимое папки, а не саму папку gorizont-site-main внутрь репозитория.
5. Вернись в GitHub Desktop. Проверь список изменений, напиши сообщение коммита, например:
   «Добавлены Миша и обновлённый конструктор персонажа».
6. Нажми Commit to main, затем Push origin.

Если GitHub Pages публикует ветку main, сайт обновится после завершения публикации.

ЧТО ИЗМЕНИЛОСЬ
